# World, winch and manual transmission validation

This upgrade retains the existing shared world identity, three spawn coordinates, journal indices, garage and original games. It appends content to a fixed 16 × 16 km world: 133.103 km of roads, 16 regions, eight lakes and 67 discoveries. It does not generate a new map on login.

## Changes and measured checks

- Six synchronized manual gears, Right Shift reverse, S service brake, automatic clutch interruption, low-gear climbing torque, bounded engine braking and unsafe-shift rejection. Flat-course actual physics speeds: 9.55 / 14.31 / 19.10 / 23.49 / 32.34 / 37.72 mph. Fourth retains the former top-speed force curve. High-speed and hill tests use real rigid-body forces.
- Clickable accessible nameplates request consent towing. Right Ctrl or the inline Accept button accepts; Left Ctrl and typing in chat cannot. The server rechecks expiry, ownership, distance and clear terrain. E/Q reel and X detaches. Parking remains tire friction and can slip under tension.
- Rejected-shift reconciliation now copies acknowledged authoritative transmission/clutch state. A real delayed-rejection prediction regression converged to a 0.0356 m position difference. Server input acknowledgment cannot roll backward when prediction clocks rebase.
- Added connected western lake/forest, northern mountain and southern canyon/prairie routes. Broad cut/fill terrain shaping removes the artificial deep road trenches found during browser inspection. The old Crown climb and optional rock-spur floors were regraded without moving their paths, original spawn coordinates or protected road centers. Granite shelf phases blend at corners instead of jumping across a polyline seam.
- Four graphics presets include PC Ultra. High/Ultra keep 72 coarse terrain tiles under bounded middle/fine streaming. Forests use instancing and matching LOD. GPU uploads process up to four groups within a 4 ms CPU budget; cells reveal atomically. A ready-cell texture masks coarse terrain in world space, preventing coarse ridges from covering cars above fine-ground silhouettes.
- Actual WebGL regression checks verify the terrain coverage fix and upload-budget behavior; shader errors are captured. Core rigid-body, water, multiplayer session, network, winch authority, transmission, save migration, shop, progression, Summit Run, basketball, drift and shipping tests pass.

## World and browser coverage

Physical route checks drove four representative new road sections, totaling 2415 m, with maximum lateral error 0.36 m, maximum pitch 0.312 radians and at least 99.9% of ticks retaining two wheel contacts. The complete old Crown traverse covered 4552 m, retaining at least two contacts on 99.963% of ticks. These checks do not imply every metre of the 133 km road network was driven.

Real browser inspections include Bracken shore, Eagles roost and the weather crown looking both inward and outward. The expedition test also drives 300 m across streamed outer-world cells. The independent two-client control test exercises all six actual number keys, reverse movement and service braking, remote gear/HUD synchronization, nameplate requests, Right Ctrl consent, chat isolation, cable rendering/reeling and parking slip. The spawn/camera test covers all three starts, orbit, zoom, recenter, camera clearance and simultaneous touch pedals/camera/gear/brake controls.

The final four-client Worker-preview run injected 70–120 ms of request delay and dropped every eleventh input request. Four independent browser contexts joined the same world and actual throttle produced a shared car-to-car push. One client disconnected during the subsequent chat check, so the run failed before towing/reconnect/frame-time measurements. A larger-viewport attempt also lost a session during setup. These are partial passes, not a claim that four-client stress reliability is solved. The separate hosted API suite passes concurrent CAS exchanges, six gears/reverse, invalid input isolation, chat, tow permission/attachment/detachment and reconnect.

The final repeated two-client browser run freshly passed all six synchronized gear/HUD selections, actual reverse motion and service braking. It then timed out on acceptance after the scripted chat-key sequence outlasted the 15-second tow-request lifetime. The test now requests fresh consent after that sequence; this final test-script adjustment has not been rerun end to end. Earlier two-client physical towing and current DOM/authority tests passed, but this final browser run is a partial pass.

## Limits

Final post-mask screenshot inspection at forest spawn, Bracken and the outward weather crown confirms four wheel contacts and all 72 horizon tiles loaded at each stop, with no JavaScript/shader errors. The screenshots still show simple canopy forms and a plain exterior horizon at the northern map edge; this does not meet the requested PC-quality art target. Software-rendered frame averages at those 960 × 600 views were 681 / 534 / 315 ms. The garage WORK IN PROGRESS banner remains in place.

The available browser renderer is software Chromium in a shared container, not a physical PC or Chromebook. A full expedition profiling run recorded 761 frames: median 116.7 ms, p95 400 ms, maximum 983.3 ms, including loading and High/Ultra screenshot views. During the actual drive, median was 116.7 ms and p95 166.7 ms. Upload CPU p95 was 0.5 ms with one 32.5 ms maximum; main streaming p95 was 0.1 ms with one 35.1 ms maximum. This is not smooth hardware performance and does not establish a Chromebook frame-rate guarantee. CPU budgets bound work submitted per frame, not every allocation, GPU upload or driver stall.

The published backend uses a singleton Worker/D1 checkpoint and shared authoritative force simulation. It advances fixed steps on active requests; it is not a dedicated continuously ticking low-latency process. The Node/SSE alternative ticks continuously at 120 Hz and should be used for larger multiplayer loads. Towing is a bounded spring/damper approximation; cables do not wrap around scenery. The strict rock-contact regression remains failing: all three optional crawl paths finish without teleports (maximum per-step movement 0.0352 m), but the raycast tire contact-plane deficit reaches 0.201 m at a sharp Redstone side shelf and 0.133 m on Lantern. The tire-envelope bump stops do not provide a complete sidewall/jointed-wheel collision model; clipping at these extreme shelves remains a known issue. The strict 0.10 m check is retained to expose it. Full 24-player load, physical-device graphics performance, every road/shoreline and long-duration Internet behavior remain unverified.
