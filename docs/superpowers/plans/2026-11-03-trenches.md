# The Trenches Implementation Plan

> Implement inline, following the supplied staged brief.

**Goal:** Add a playable freshman offensive-line football game to Afterclass Garage.
**Architecture:** Existing static HTML routes, UMD JavaScript simulation modules, Canvas pixel rendering, browser-local saves. No new runtime dependencies.
**Spec:** ../specs/2026-11-03-trenches-request.md

## Constraints and decisions
- Keep all five existing game routes, wallet profiles, and cache assets intact.
- Add `trenches.html`, `trenches.css`, `trenches.js` (UI/audio/input), `trenches-core.js` (play and match simulation), `trenches-data.js` (rosters, season, saves), `trenches-art.js` (Canvas renderer), and `trenches-cover.svg`.
- Public source contains aliases. Supplied names are provided as a separate private JSON import outside the repository. Known positions are retained; unknown positions/numbers remain blank. Unassigned roster members do not silently receive field positions.
- Eight fictional practice matchups, four 90-second arcade quarters, automatic PATs, simulated opposing possessions, ties allowed, no invented real schedule or postseason.
- Saves use a new versioned key and never replace the Garage wallet. Completed matches/drills award deduplicated shared points through `awardGarage`.
