# City Heist — Bluewater

An original Canvas 2D continuous cops/criminals extraction city, added alongside all existing Afterclass Garage games. Fixed 3,200 × 2,400 waterfront map: three connected island districts, causeways, beaches, docks, parks, 34 enterable buildings and eight robbery businesses. Artwork and sprites are drawn from code; the supplied screenshot informed the blue palette and road details, not copied assets.

## Play

Run `node over-the-hill/server.cjs` and visit **http://localhost:8001/city-heist/**. This single process serves both games and the garage. It uses `work/city-heist.json` for City Heist alone (`CITY_DATA` overrides it); existing game files and storage keys remain unchanged. Use one Node replica, persistent disk, HTTPS and uncached API requests. Back up the JSON file. The hosted Sites build instead uses the additive `city_shared` D1 table and revision compare-and-swap writes; run the existing `node hosting/package.cjs` workflow with all three journaled migrations. Never run multiple independent Node replicas against one JSON file.

- Choose a temporary name, join the real server, and deploy from the hideout in a free rental or selected owned vehicle. Everyone starts civilian; up to 24 active explorers, with at most 12 police/12 criminals.
- WASD/arrows move; in cars W/S throttle/reverse and A/D steer. Mouse aims; hold click for fictional, non-graphic pulses. 1–5 select hotbar slots; pulse is slot1, a deployed field patch is slot2, armor is passive.
- E enters/exits nearby cars, enlists at the police station, returns civilians/officers to the hideout, or extracts criminals at a green city exit. Hold F for four seconds to become criminal. Hold E inside a robbery business to collect a bundle every ten seconds. Leaving/releasing resets that bundle timer. Higher security and longer uninterrupted stays offer richer loot; high-security sites slowly wear down health. Robbery immediately alerts online officers.
- M or the minimap opens the full map; click to place a waypoint. Enter opens/sends chat; Esc closes it. People offers local mute/unmute and reports.
- Extraction secures carried goods, unused deployed gear and the current vehicle. Rentals are unlimited and never become owned. An owned vehicle is removed from storage on deployment and retained only if extracted; elimination or extraction in a different vehicle loses it. Unsecured loot and deployed gear are lost on elimination. Safe stash/cash are retained. Stash supports 200 goods, 30 cars and 50 equipment items. Uncommon world cars return after a ten-minute extraction/destruction cooldown.
- Smugglers buy extracted loot and owned cars, and sell equipment. Equip up to five stash items for the next run. Police receive standard gear on enlistment. Civilians cannot hurt or be hurt by arcade combat; opponents' pulses respect walls. There are no AI police or fake players.

## Authority and recovery

The server accepts bounded controls and actions, never client positions, currency, loot, health or ownership. The common core steps at 40 Hz with Earth-independent arcade movement, collision walls/furniture and vehicle resistance. Stale controls stop after 600 ms. HTTP exchanges run at approximately 10 Hz with remote interpolation and bounded local visual prediction/correction. The hosted Worker advances the continuous shared simulation on requests, rather than a dedicated always-ticking process; D1 latency and contention affect update cadence. Catch-up applies the first half-second of the held-input window, rather than discarding it when a hosted exchange arrives late; this is not rollback or lag-compensated hit detection.

Guest keys are 192-bit random bearer secrets saved in the browser. Public IDs are derived from SHA-256; raw keys never appear in public snapshots or database checkpoints. Server profiles persist gear, cash, stash and run position. Losing/clearing browser storage loses guest access; there is no account recovery or cross-device sync. Do not share the key. Rejoining restores the same run. After three minutes without contact a deployed run is lost, preventing permanent logout storage; active-slot counts expire after twenty seconds. This first implementation stores guest profiles in the shared JSON city checkpoint rather than a sharded database; very large lifetime guest populations require a storage migration and are not verified.

Actions use server-remembered monotonically increasing IDs to resist replay. D1 transactions use revision CAS; Node serializes commits and atomically renames its checkpoint file. Chat is limited to 160 characters, one message/1.2 seconds and eight/minute, with a basic English word filter and text-only rendering. Reports are private bounded records, not a staffed moderation service or automatic bans. Mute is local. API same-origin checks and body limits apply. New guest creation is limited to 60 keys/hour per hashed network address; reconnects do not consume that limit.

## Verified and limitations

`node --test city-heist/test-core.cjs city-heist/test-api.cjs` verifies role hold/capacity, robbery cadence/alerts, collision and doorway access, extraction/currency, replay/forged inputs, gear selection, weapon damage/civilian protection/wall blocking, owned car elimination/abandon loss and guest privacy/reconnect.

`node city-heist/test-browser.cjs` uses two independent Chromium contexts and actual keyboard input for deploy/driving, criminal hold, chat, full map/waypoints and reconnect; screenshots are inspected. `node city-heist/test-expedition.cjs` starts a disposable server with players positioned at a store and police station, then tests real enlistment, alert delivery, ten-second robbery, interior roof fading, walking out through the doorway and along the streets to extraction, selling goods and cash surviving a full server restart. Starting fixtures are not claimed as navigation from spawn.

`TEST_BASE_URL=http://127.0.0.1:8005 node city-heist/test-hosted.cjs` tests the built Worker with a migrated SQLite D1 adapter: four concurrent guests, CAS purchases, replay protection, cash authority, token privacy, deployment, shared chat and reconnect. Existing Over the Hill hosted tests also pass against that adapter. Existing garage progression/wallet and map invariance checks are run before packaging.

Not yet verified: 24 simultaneous browser clients, long-duration public-network latency/packet loss, physical Chromebook frame rates, browser combat/elimination under adverse networking, all routes/districts by driving, comprehensive moderation or large persistent guest populations. Combat, car acquisition/loss and gear use have core tests but not exhaustive multi-browser stress coverage. The offline cache stores the shell and artwork only; City Heist needs the real server to play. Other games retain their offline behavior.
